# EMAIL_PROFILE_IIH.md

IIH-specific policy overlay for email operations.

Use with: `EMAIL_OPERATIONS_MASTER.md`

## 1) Scope
- IIH institutional work
- IIH stakeholder communications
- IIH reports/finance/program operations

## 2) Mandatory Rules
- Never send any IIH email without explicit instruction in current thread.
- For inbound IIH requests, draft/review only until approval to send.
- Address Temi by title (Managing Director / MD), not first name, in IIH emails.
- Always CC `temi@iih.ng` on IIH outbound emails sent on instruction.

## 3) Outbound Formatting Rules (when send is authorized)
- Send as HTML.
- Never attach `.md` files.
- Prefer `.docx`, `.pdf`, `.xlsx` attachments.
- Include executive summary in body for report emails.

## 4) Signature (mandatory)
For HTML email, use the IIH logo/table signature template:
`signatures/clawdia_iih_signature.html`

Embed `signatures/clawdia_iih_logo.png` inline with CID `iih-logo`.

- IHS Towers domains/emails are highest priority.
- Items with <24h deadline stay urgent until treated/resolved.
