## **ANE Repository Summary**

**ANE (Apple Neural Engine)** is a research project that enables **training neural networks directly on Apple's Neural Engine** using reverse-engineered private APIs. Key points:

### **What ANE Does:**
1. **Bypasses CoreML restrictions** - Uses private `_ANEClient`/`_ANECompiler` APIs to run custom compute graphs
2. **Supports training** - Not just inference (unlike official CoreML)
3. **Dynamic pipeline** - Weights can change without recompilation
4. **INT8 quantization** - 1.88x throughput improvement over FP16
5. **GPU↔ANE pipeline** - Zero-copy shared memory for hybrid inference

### **Current Capabilities:**
- **Stories110M** (109M params): 91ms/step on M4
- **Qwen3-0.6B** (596M params): 412ms/step on M4  
- **INT8 W8A8**: 35.1 TOPS peak (M4, H16G)
- **GPU prefill + ANE decode** pipeline for inference

### **Limitations:**
- Research project, not production-ready
- Low utilization (~5-9% of peak)
- Many ops still fall back to CPU
- ~119 compile limit per process (requires `exec()` restart workaround)
