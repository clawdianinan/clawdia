**Actions Taken**
- Backend changes:
  - `src/middleware/auth.ts`: extended dev auth bypass to honor `X-Dev-User-Id` and `X-Dev-Role` headers when `ALLOW_DEV_AUTH_BYPASS=true`. This allows tests to set arbitrary user IDs without login.
  - `src/routes/jobs.ts`: added `POST /api/jobs` (protected, employer only). Handler auto‑creates an `employer_accounts` record if none exists for the user, then inserts the job listing.
  - Imports updated to include `requireAuth` and `requireEmployer`.
- QA test suite:
  - `qa-tests/test/ownership-enforcement.test.js` rewritten to be fully self‑contained. It generates UUIDs for all users, uses dev headers directly, and creates all required data (jobs, profiles, applications, threads) in the `before` hook.
  - Removed dependency on `qa-tests/helpers.js` and `.env.test` for the test itself.
  - All original assertions preserved; rate‑limiting, XSS sanitization, read‑receipt, and context validation tests remain.
- Documentation: updated `TESTING_PLAN.md` to reflect the new flow (dev headers, no seed needed).
