## Architecture
- **Frontend:** Next.js 15 App Router + Tailwind CSS
- **Backend:** Node.js/Express monorepo
- **Database:** PostgreSQL (Supabase local dev; cloud-ready for Supabase/Neon)
- **Auth:** Supabase Auth (email/password, JWT)
- **Storage:** Supabase Storage (credentials vault, RLS, signed URLs)
- **Realtime:** Supabase Realtime (messaging/notifications)
- **Search:** PostgreSQL full-text search (upgradeable to Elasticsearch)
- **Payments:** Stripe
- **Push:** Firebase Cloud Messaging
- **Monitoring:** Sentry, LogRocket, UptimeRobot
- **Compliance:** HIPAA, GDPR, SOC 2 Type II prep

---

## Key Features Implemented
- Legal: Privacy, Terms, consent management, data export/deletion
- Jobs: Search API, Map view (Mapbox), structured listings, one-click apply
- Profiles: Wizard, credentials vault (encrypted upload), GIS picker, social export
- Applications & Hiring: Interview scheduling, offer management, AI cover letters (Claude)

- Operations: Admin dashboard, user management, billing/subscriptions, support tickets
- DevEx: OpenAPI 3.0 docs, TypeScript SDK, CI/CD with security scanning, load testing
- UX: Mobile PWA, onboarding flow, referral program, accessibility audit
- Infra: CDN (Cloudflare), rate limiting, geo-redundant backups, feature flags, A/B testing

## Dev Setup (Supabase Local)
```bash
# Start Supabase stack (Docker)
docker-compose -f docker-compose.supabase.yml up -d
# or: supabase start

# Initialize DB and apply migrations
npm run supabase:reset   # uses supabase db reset + manual apply

# Start app (ports: frontend 3003, backend 3004, admin 3005)
pnpm dev
```

Services run on:
- Front: http://localhost:3003
- API: http://localhost:3004
- Admin: http://localhost:3005
- Supabase: Auth 54325, Storage 54327, Realtime 54326, Postgres 54322 (db: mdresident)

---

## Database Schema
Tables: `users`, `resident_profiles`, `credential_documents`, `job_listings`, `applications`, `offers`, `employer_accounts`, `message_threads`, `messages`, plus audit/support/analytics tables. HIPAA-conscious: UUIDs, pgcrypto, cascade rules, audit timestamps, BAA tracking.
