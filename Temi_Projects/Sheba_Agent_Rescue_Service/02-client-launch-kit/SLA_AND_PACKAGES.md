# SLA & Packages (Client-Ready)

## Package 1: Rescue Sprint
- Response: within 4-12 hours
- Restore target: 24-48 hours
- Output: fix + rollback notes + post-incident summary

## Package 2: Stability Hardening
- Scope: retries, idempotency, alerting, failover rules
- Duration: 2-5 business days
- Output: hardened workflows + monitoring checklist

## Package 3: Managed Reliability (Monthly)
- Weekly health checks
- Incident response window
- Monthly reliability report + optimization actions
