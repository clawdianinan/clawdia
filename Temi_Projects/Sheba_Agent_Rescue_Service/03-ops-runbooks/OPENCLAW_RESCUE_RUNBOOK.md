# OpenClaw Rescue Runbook

## Phase 1: Triage (0-60 min)
1. Confirm incident severity and blast radius.
2. Capture logs, last known good state, recent changes.
3. Freeze non-essential changes.

## Phase 2: Stabilize
1. Apply reversible fix first.
2. Validate core workflow path.
3. Monitor for regression for agreed window.

## Phase 3: Recover
1. Restore full workflow coverage.
2. Re-enable integrations incrementally.
3. Confirm client acceptance criteria.

## Phase 4: Prevent
1. Root cause classification.
2. Add guardrails (alerts, retries, fallback).
3. Deliver post-incident report and action list.
