# PRDForge Quantity Analysis & Adjustment

## Current Structure Analysis

### Current Credit-to-Price Ratios:
1. **Free**: $0 → 10 credits = ∞ value (free)
2. **Starter**: $9 → 100 credits = $0.09/credit
3. **Pro**: $29 → 500 credits = $0.058/credit

### Current Discount Analysis:
- **Pro vs Starter**: 35.6% cheaper per credit ($0.058 vs $0.09)
- **Yearly Savings**: ~17% (2 months free)

### Current Project Limits:
- **Free**: 3 projects (3.33 credits/project based on monthly allocation)
- **Starter**: 15 projects (6.67 credits/project)
- **Pro**: Unlimited projects

## Issues with Current Quantities:

1. **Free Tier Too Restrictive**: Only 10 credits = ~3 PRD generations
2. **Starter Tier Weak Value**: $9 for only 100 credits = ~33 PRD generations
3. **Pro Tier Good Discount**: But could be more compelling
4. **Project Limits Misaligned**: Free users hit project limit before credit limit

## Adjustment Goals:

1. **Free Tier**: More generous trial (increase credits significantly)
2. **Starter Tier**: Clear 10x+ value from Free tier
3. **Pro Tier**: Maintain ~35% discount per credit vs Starter
4. **Project Limits**: Align with credit allocation
5. **Export Value**: Paid tiers should have clear export advantage

## Recommended Adjustments:

### Option A (Conservative):
- **Free**: 25 credits (2.5x increase), 5 projects
- **Starter**: 250 credits (2.5x increase), 25 projects  
- **Pro**: 1000 credits (2x increase), unlimited projects

### Option B (Aggressive):
- **Free**: 50 credits (5x increase), 10 projects
- **Starter**: 500 credits (5x increase), 50 projects
- **Pro**: 2000 credits (4x increase), unlimited projects

### Option C (Balanced - Recommended):
- **Free**: 30 credits (3x increase), 5 projects
- **Starter**: 300 credits (3x increase), 30 projects
- **Pro**: 1000 credits (2x increase), unlimited projects

## Credit-to-Price Analysis for Option C:

1. **Free**: $0 → 30 credits = ∞ value
2. **Starter**: $9 → 300 credits = $0.03/credit
3. **Pro**: $29 → 1000 credits = $0.029/credit

**Discount Analysis:**
- Pro vs Starter: 3.3% cheaper per credit (maintains incentive but more balanced)
- Starter vs Free: Clear 10x value jump
- Yearly savings: Still ~17%

## Project Limit Rationale:

### Free Tier (30 credits, 5 projects):
- 6 credits/project allocation
- Allows ~5 full PRD generations (using 6 credits each)
- Project limit aligns with credit limit

### Starter Tier (300 credits, 30 projects):
- 10 credits/project allocation  
- Allows ~30 full PRD generations
- Clear 6x project increase from Free

### Pro Tier (1000 credits, unlimited):
- No project constraints
- Power users can focus on volume

## Model Access Strategy:

**Keep current model differentiation:**
- **Free**: Standard models only
- **Starter**: Standard + Premium models
- **Pro**: All models (Standard + Premium + Advanced)

## Export Value Proposition:

**Paid tiers get unlimited exports** - This remains the key upgrade driver from Free tier's $5/project export fee.

## Implementation Impact:

1. **User Experience**: More generous limits reduce friction
2. **Conversion**: Better Free→Starter value proposition
3. **Retention**: Pro tier becomes more compelling for power users
4. **Revenue**: Same pricing, better perceived value

## Final Recommended Structure:

### 🆓 **Free Plan** - $0/month
- **Credits**: 30 credits/month (3x increase)
- **Projects**: 5 active projects
- **Export**: NOT included ($5 per project export)
- **AI Models**: Standard models only
- **Value**: ~5 full PRD generations/month

### 🚀 **Starter Plan** - $9/month ($90/year)
- **Credits**: 300 credits/month (3x increase)
- **Projects**: 30 active projects (2x increase)
- **Export**: INCLUDED (unlimited exports, all formats)
- **AI Models**: Standard + Premium models
- **Value**: ~50 full PRD generations/month
- **Savings**: ~17% with annual billing

### ⚡ **Pro Plan** - $29/month ($290/year)
- **Credits**: 1000 credits/month (2x increase)
- **Projects**: UNLIMITED projects
- **Export**: INCLUDED (unlimited exports, all formats)
- **AI Models**: Standard + Premium + Advanced models
- **Value**: ~166 full PRD generations/month
- **Savings**: ~17% with annual billing
- **Credit Discount**: 3.3% cheaper per credit vs Starter

## Justification:

1. **Free Tier**: More generous trial (30 credits = real testing capability)
2. **Starter Tier**: Clear 10x value jump from Free
3. **Pro Tier**: Maintains discount incentive while offering significant volume
4. **Project Limits**: Aligned with credit allocation
5. **Pricing Preserved**: All adjustments maintain $0/$9/$29 pricing

This structure maintains the same pricing logic while offering significantly better value, which should improve conversion and retention.
