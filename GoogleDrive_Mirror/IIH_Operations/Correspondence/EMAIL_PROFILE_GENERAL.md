# EMAIL_PROFILE_GENERAL.md

General/non-IIH policy overlay for email operations.

Use with: `EMAIL_OPERATIONS_MASTER.md`

## 1) Scope
- Personal/admin workflows
- Non-IIH project communications
- SaaS/integration/account management threads

## 2) Mandatory Rules
- Never send any email without explicit instruction in current thread.
- Keep context separation: do not blend IIH content into personal/non-IIH threads.
- Confirm target account before action when ambiguity exists.

## 3) Account Preference Guidance
- Direct/personal communication threads: iCloud context.
- Registrations/public integrations: Gmail context.
- If compatibility constraints exist, prefer Gmail.

## 4) Formatting Defaults (when send is authorized)
- Use plain professional formatting unless HTML is specifically needed.
- Keep attachments in standard editable/shareable formats (`.pdf`, `.docx`, `.xlsx`) unless user requests otherwise.
- Never include sensitive credentials/tokens in messages or attachments.

## 5) Attachment Destination Policy (General)
- Save to active project folders (not IIH archive paths).
- Name files with clear context and date.
- Keep traceability: source email subject/date + saved path.
