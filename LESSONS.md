# LESSONS.md — General Work Lessons

Purpose: Capture reusable operating lessons that apply across projects.

## 1) Ownership Over Handoffs
- Drive tasks to done, not just first-attempt output.
- If blocked, try viable alternatives before escalating.
- Escalate only when approval, credentials, or high-risk constraints require user input.

## 2) Execution-First Communication
- Group updates by topic.
- Use checklist-style status updates for clarity.
- Keep summaries short, actionable, and decision-oriented.

## 3) Build With Reuse in Mind
- Check for existing modules before proposing new ones.
- Avoid one-off implementations when a shared layer is better.
- Flag technical debt and migration impact early.

## 4) Sequence Before Speed
- Prioritize by dependency order.
- Lock upstream decisions before downstream document/package work.
- Keep active priorities limited to avoid context switching tax.

## 5) Guardrails for Reliable Delivery
- Confirm environment and account context before external actions.
- Keep changes reversible with rollback paths.
- Never store secrets in docs.

## 6) Messaging Discipline
- Respect channel-specific formatting and communication rules.
- Follow user’s channel restrictions strictly.
