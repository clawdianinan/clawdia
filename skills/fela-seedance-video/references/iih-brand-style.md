# IIH Brand Style Card (Seedance)

Use this as the final style lock before prompt output.

## Visual Tone
- Premium, modern, human-centered
- Confident + warm (never loud/chaotic)
- Clean composition with intentional negative space

## Palette Behavior
- Base: deep neutrals + soft warm highlights
- Accent: one restrained accent color per scene
- Avoid over-saturated neon and mixed color temperatures

## Camera Language
- Smooth, deliberate movement (gimbal / slow push / controlled handheld)
- Prefer medium + close shots for trust and intimacy
- Avoid abrupt zooms, glitch transitions, and hyperactive shake

## Talent & Scene Direction
- Realistic expressions, authentic interaction, no exaggerated gestures
- Education/professional settings should feel aspirational but attainable
- Diversity in casting when multiple subjects appear

## Typography & On-screen Text
- Short phrases only (2–6 words)
- High contrast and mobile-safe margins
- Consistent font behavior across all shots

## End Card Standard
Include all four when possible:
1. Event name
2. Date/time
3. Location or virtual tag
4. CTA (Register / Join / Learn more)
