# Convex CLI Reference

## Commands

### convex dev
Develop against a dev deployment, watching for changes.

**Usage:**
```bash
npx convex dev [options]
```

**Options:**
- `--tail-logs <mode>`: Control log output: `always`, `disable`, or default (pause during deploys).
- `--push`: Push local code before starting dev server.
- `--run <function>`: Run a function after push.
- `--no-watch`: Disable watching for changes.
- `--no-types`: Skip TypeScript type generation.
- `--deployment <name>`: Use a specific deployment (default: dev deployment).

### convex deploy
Deploy to your production deployment (or preview deployment if using a preview deploy key).

**Usage:**
```bash
npx convex deploy [options]
```

**Options:**
- `--cmd <command>`: Run a command before deploying (e.g., build script). The command receives CONVEX_URL environment variable.
- `--cmd-url-env-var-name <name>`: Custom environment variable name for the deployment URL.
- `--preview-create <name>`: Create a preview deployment with the given name.
- `--preview-run <function>`: Run a function after deploying to preview.
- `--prod`: Deploy to production (default behavior with CONVEX_DEPLOY_KEY).
- `--typecheck`: Typecheck functions before deploying (default: true).
- `--no-typecheck`: Skip type checking.

### convex deployment
Manage deployments.

**Usage:**
```bash
npx convex deployment [subcommand]
```

Subcommands:
- `list`: List deployments for the current project.
- `create`: Create a new deployment.
- `delete`: Delete a deployment.
- `promote`: Promote a deployment to production.

### convex run
Run a function (query, mutation, or action) on your deployment.

**Usage:**
```bash
npx convex run <functionName> [args]
```

**Arguments:**
- `functionName`: Name of the function (e.g., `messages:list`).
- `args`: JSON object of arguments (optional).

**Options:**
- `--watch`: Live update query results.
- `--push`: Push local code before running.
- `--prod`: Run on production deployment.

### convex import
Import data from a file to your deployment.

**Usage:**
```bash
npx convex import [options] <path>
```

**Options:**
- `--table <tableName>`: Target table name.
- `--format <format>`: Input format (`json`, `csv`).

### convex export
Export data from your deployment to a ZIP file.

**Usage:**
```bash
npx convex export [options]
```

**Options:**
- `--path <directory>`: Output directory or file path.
- `--include-file-storage`: Include file storage data.

### convex env
Set and view environment variables.

**Usage:**
```bash
npx convex env list
npx convex env get <name>
npx convex env set <name> <value>
npx convex env remove <name>
```

**Options:**
- `--prod`: Manage production deployment variables.
- `--from-file <file>`: Set variables from a file.
- `--force`: Overwrite existing variables.

### convex data
List tables and print data from your database.

**Usage:**
```bash
npx convex data [options] [table]
```

**Options:**
- `--limit <n>`: Limit number of rows.
- `--order <asc|desc>`: Order by `_creationTime`.

### convex logs
Watch logs from your deployment.

**Usage:**
```bash
npx convex logs [options]
```

**Options:**
- `--prod`: Tail production logs.
- `--deployment <name>`: Specific deployment.

### convex dashboard
Open the Convex dashboard in the browser.

### convex docs
Open the Convex documentation.

### convex login
Login to Convex.

**Options:**
- `--device-name <name>`: Provide a name for the device.
- `--no-open`: Don't open browser automatically.

### convex logout
Log out of Convex on this machine.

### convex codegen
Generate backend type definitions.

### convex update
Print instructions for updating the convex package.

### convex function-spec
List function metadata from your deployment.

### convex insights
Show health insights for your deployment.

### convex disable-local-deployments
Stop using a local deployment for the current project.

### convex mcp
Manage the Model Context Protocol server for Convex [BETA].

### convex ai-files
Manage Convex AI files.

## Environment Variables

- `CONVEX_DEPLOYMENT`: The deployment name (e.g., `happy-animal-123`). Used during development.
- `CONVEX_DEPLOY_KEY`: A deploy key for deploying to a specific deployment (production or preview).
- `CONVEX_URL`: The URL of the deployment (automatically set by `convex dev` and `convex deploy --cmd`).
- `CONVEX_API_TOKEN`: Team access token for Management API (used by scripts).

## Project Configuration

- `convex/`: Directory containing Convex functions (`convex/`).
- `convex.json`: Project configuration file (generated by `convex dev`).
- `.env.local`: Contains `CONVEX_DEPLOYMENT` (generated by `convex dev`).

## Common Workflows

### Starting a new project
```bash
mkdir myapp
cd myapp
npx convex dev   # follow prompts to create project
```

### Deploying to production
```bash
# Set deploy key (optional, if not using CONVEX_DEPLOYMENT)
export CONVEX_DEPLOY_KEY=your_key
npx convex deploy
```

### Managing environment variables
```bash
npx convex env set API_KEY secret
npx convex env list
```

### Running a function
```bash
npx convex run myquery '{"param": "value"}'
```

### Importing data
```bash
npx convex import --table messages data.json
```

### Exporting data
```bash
npx convex export --path backup.zip
```
