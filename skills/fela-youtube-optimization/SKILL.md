# YouTube Optimization Skill

## Core Principles

### Algorithm-Friendly Content
- **First 30 seconds**: Hook + value proposition + channel branding
- **Retention spikes**: Place key moments at 0:30, 2:00, 5:00 marks
- **Audience retention**: Aim for >60% average view duration

### Thumbnail Design Rules
1. **Face/emotion**: Human/ape face with clear emotion (surprise, curiosity, intensity)
2. **High contrast**: Bright subject on dark background or vice versa
3. **Text overlay**: 3-5 words max, large bold font, drop shadow
4. **Brand consistency**: AOZ series thumbnails use consistent color palette (orange/black/gold)
5. **Mystery element**: Hint at story conflict without spoiling

### Title Optimization
- **Length**: 50-70 characters optimal
- **Structure**: [Hook] + [Keyword] + [Benefit/Question]
- **Examples**: 
  - "Annunaki Apes Arrive in Africa - What Happens Next Will Shock You"
  - "The White Apes' Secret Agenda - Nigeria's History Retold"
  - "Why Zamoonda's Leaders Betrayed Their People | AOZ Episode 3"

### Description & SEO
- **First 3 lines**: Video summary + CTA (subscribe, like, comment)
- **Timestamps**: Every 2-3 minutes for key moments
- **Keywords**: 5-7 relevant tags in description
- **Links**: Episode playlist, social media, website

## Workflow

### 1. Pre-Publish Checklist
- [ ] Thumbnail passes "3-second test" (clear message at glance)
- [ ] Title includes primary keyword
- [ ] Description has complete episode summary
- [ ] Tags include series name + episode theme
- [ ] End screen cards configured (next episode, subscribe, playlist)

### 2. Post-Publish Optimization
- Monitor first 48-hour performance
- Check audience retention graphs for drop-off points
- Update title/thumbnail if CTR < 5%
- Pin top-performing comment
- Add chapters if missing

## AOZ-Specific Guidelines

### Series Branding
- Thumbnail border: Orange (#FF6B35) for AOZ series
- Logo placement: Bottom-right corner at 10% opacity
- Episode numbering: "S01E01" in top-left

### Content Strategy
- **Episode hooks**: Start with dramatic cold open
- **Mid-roll spikes**: Plot twist at 3:00 mark
- **Ending CTA**: "Subscribe for next episode" + social links
