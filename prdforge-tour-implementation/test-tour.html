Quick Integration Steps

  1. Install dependency: npm install react-joyride
  2. Copy tour components to your project's src/ directory
  3. Wrap your app with TourProvider in your main App.tsx
  4. Add data-tour attributes to target elements in your dashboard
  5. Trigger the tour after successful user signup with startTour()

Example Integration Code

// 1. Wrap your app with TourProvider <TourProvider autoStart={false} onTourStart={() => console.log('Tour started')} onTourComplete={() => console.log('Tour completed')} > <YourApp /> <Tour /> </TourProvider> // 2. Add data-tour attributes to elements <div data-tour="dashboard">Welcome</div> <button data-tour="create-prd-button">Create PRD</button> // 3. Trigger tour after signup const { startTour } = useTour(); const handleSignupSuccess = () => { setTimeout(() => startTour(), 1000); };

Tour Flow
