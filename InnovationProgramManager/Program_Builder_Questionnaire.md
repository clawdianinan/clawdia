# Program Builder Questionnaire

Use this intake to auto-generate a program blueprint.

## A) Program Identity
1. Program name
2. Program type (accelerator / grant / hybrid / rolling)
3. Sector focus (generalist or vertical)
4. Geography and eligibility scope

## B) Cohort Design
5. Target cohort size
6. Program duration and cadence
7. Delivery mode (in-person/hybrid/virtual)
8. Key milestones and graduation criteria

## C) Participant Profile
9. Startup stage (idea/MVP/early revenue/growth)
10. Required team composition criteria
11. Required traction thresholds (if any)
12. Inclusion/diversity goals

## D) Selection Framework
13. Application components (form/video/deck/references)
14. Scoring rubric dimensions and weights
15. Panel composition and decision authority
16. Selection timeline and communication SLA

## E) Curriculum & Support
17. Core learning modules
18. Mentorship model (ratio, frequency, match logic)
19. Expert sessions/workshops required
20. Demo day / final showcase requirements

## F) Budget & Funding
21. Funding model (equity, grant, matching, hybrid)
22. Total budget envelope
23. Cost categories and ceilings
24. Disbursement logic and evidence requirements
25. Partner contributions (cash/in-kind)

## G) Operations & Governance
26. Core team roles and responsibilities
27. Meeting/reporting cadence
28. Risk triggers and escalation rules
29. Data/privacy and compliance requirements

## H) Outcomes & Reporting
30. Primary KPIs (completion, capital raised, revenue, jobs, etc.)
31. Reporting recipients (leadership/funders/public)
32. Reporting frequency and format
33. Alumni support model and follow-up period
