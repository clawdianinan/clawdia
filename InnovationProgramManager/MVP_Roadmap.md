# MVP Roadmap

## Goal
Launch a usable v1 that supports one full cohort lifecycle end-to-end.

## Phase 1 (0-6 weeks): Foundation
- Program template builder
- Questionnaire intake
- Cohort calendar generation
- Basic user roles (Admin, Program Manager, Reviewer)

## Phase 2 (7-12 weeks): Selection + Delivery Core
- Application pipeline and scoring workflow
- Interview and panel decision support
- Milestone tracker
- Session and mentor scheduling basics

## Phase 3 (13-18 weeks): Budget + Reporting
- Budget engine v1 with scenario planning
- Disbursement tracker with approvals
- Dashboard for delivery + KPI + budget variance
- Exportable end-of-cohort report

## Phase 4 (19-24 weeks): Hardening
- Compliance evidence vault
- Alumni tracking (3/6/12 month)
- Template library expansion (accelerator, grant, hybrid)
- QA, onboarding guides, pilot rollout

## MVP Success Criteria
1. Run one complete cohort without external spreadsheets
2. Generate monthly stakeholder report in <15 minutes
3. Track budget variance with <=5% reconciliation gap
4. Capture milestone evidence for all disbursement events
