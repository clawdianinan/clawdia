# Budget Engine Model

## Purpose
Provide scenario-driven budgeting for innovation programs with automatic unit economics and milestone-linked disbursements.

## Inputs
- Program type
- Cohort size
- Duration (weeks/months)
- Delivery mode
- Funding model (equity/grant/hybrid)
- Cost assumptions by category
- Partner credits/contributions

## Core Calculations
1. Total program cost
2. Cost per startup
3. Cost per graduate (adjusted by completion rate)
4. Fixed vs variable ratio
5. Burn profile by month
6. Disbursement schedule by milestone
7. Budget variance (planned vs actual)

## Scenario Modes
- Conservative
- Expected
- Aggressive

## Cost Categories (minimum)
- Team compensation
- Curriculum delivery
- Mentor/expert fees
- Founder support/stipends
- Events/logistics
- Software/tools
- Monitoring/compliance
- Contingency

## Controls
- Ceiling alerts by category
- Overrun alerts by period
- Evidence-required flag before disbursement release
- Approval workflow for budget changes

## Outputs
- Budget summary dashboard
- Monthly cashflow table
- Disbursement register
- Variance and forecast report
