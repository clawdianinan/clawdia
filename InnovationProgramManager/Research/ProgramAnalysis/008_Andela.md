# Program Analysis: Andela

## 1. Program Name & Organization
- **Program Name:** Andela Talent Marketplace / Talent Enablement Programs
- **Organization:** Andela
- **Year Founded:** 2014
- **Headquarters:** Founded in Lagos; now global remote-first operations

## 2. Geographic Focus & Reach
- **Primary Focus:** Global talent matching with strong Africa and emerging-market roots
- **Regional Focus:** Multi-region network across 100+ countries (publicly reported)

## 3. Program Structure
- Not a classic accelerator; talent network and enterprise staffing platform
- Includes talent assessment, matching, and project/team engagement models

## 4. Curriculum Framework
- Career/talent enablement resources, skill verification, client-readiness pathways

## 5. Financial Model
- Marketplace/service revenue via talent placement and managed team offerings
- No founder equity accelerator model

## 6. Selection Process
- Screening, technical assessments, and profile validation for talent admission

## 7. Success Metrics
- Large global talent network and enterprise client base publicly cited

## 8. Operational Insights
- AI/data-enabled matching model at marketplace scale
- Distributed operations with cross-border compliance/work orchestration

## 9. Publicly Available Templates
- Public talent application and employer engagement forms
