# Program Analysis: iHub

## 1. Program Name & Organization
- **Program Name:** iHub Startup Support & Innovation Programs
- **Organization:** iHub (part of CcHUB group since acquisition)
- **Year Founded:** 2010
- **Headquarters:** Nairobi, Kenya

## 2. Geographic Focus & Reach
- **Primary Focus:** Kenya with regional African collaborations
- **Physical Location:** Nairobi innovation campus/ecosystem
- **Regional Focus:** East Africa + cross-country thematic programs

## 3. Program Structure
- Hub + program stack model (incubation/acceleration/challenges/fellowships)
- Program durations vary by initiative (commonly multi-month cohorts)

## 4. Curriculum Framework
- Startup development, product/market, advisory, investor readiness, ecosystem access

## 5. Financial Model
- Mix of donor/corporate-funded equity-free programming and ecosystem support

## 6. Selection Process
