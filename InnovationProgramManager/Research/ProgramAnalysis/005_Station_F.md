# Program Analysis: Station F

## 1. Program Name & Organization
- **Program Name:** Station F Founders Program (plus multiple partner programs)
- **Organization:** STATION F
- **Year Founded:** 2017 (campus launch)
- **Headquarters:** Paris, France

## 2. Geographic Focus & Reach
- **Primary Focus:** France/Europe with international founders
- **Physical Location:** Paris (Station F campus)
- **Regional Focus:** EU and global startups relocating/operating in Paris
- **Global Reach:** 1,000+ startups hosted on campus across programs (publicly cited ecosystem scale)

## 3. Program Structure
### 3.1 Duration
- **Program Length:** Founders Program commonly stated as ~3–18 months
- **Batch Frequency:** Multiple intakes yearly
- **Example Schedule:** Application + committee review + onboarding cycle

### 3.2 Format
- **Primary Format:** In-person-first campus program with hybrid elements
- **Core Components:** Workspace, mentorship, workshops, investor access, partner perks
- **Location Flexibility:** Requires active engagement in Paris ecosystem

### 3.3 Cohort Size
- **Batch Size:** Varies by program; Founders Program runs selective cohorts
- **Group Structure:** Campus-wide multi-program structure
- **Annual Capacity:** Large-scale multi-program intake
