# Program Analysis: Microsoft for Startups

## 1. Program Name & Organization
- **Program Name:** Microsoft for Startups (Founders Hub)
- **Organization:** Microsoft
- **Headquarters:** Redmond, USA

## 2. Geographic Focus & Reach
- **Primary Focus:** Global
- **Regional Focus:** Multi-country eligibility with local ecosystem partnerships

## 3. Program Structure
- Staged support model based on startup maturity and technical needs

- Technical architecture support, GTM programs, mentorship, sales enablement

- **Type:** Non-dilutive support (credits/benefits), partner perks, marketplace pathways

## 6. Selection Process
- Online application + eligibility checks and onboarding by stage

## 7. Success Metrics
- Cloud adoption, product maturity, partner/customer traction

## 8. Operational Insights
