# Operational Best Practices

## Operational Design Principles from Global Benchmarks
1. **Design for cadence, not chaos:** fixed weekly rituals improve outcomes.
2. **Run selection like product QA:** use rubrics, panel diversity, and scoring consistency.
3. **Mentor quality > mentor quantity:** fit and follow-through matter most.
4. **Make evidence capture native:** every milestone should produce an artifact.
5. **Treat alumni as a product layer:** post-program support is part of the value proposition.

## End-to-End Operating Workflow
1. Program configuration (template + calendar + budget)
2. Intake and application scoring
3. Cohort construction and onboarding
4. Delivery (sessions, mentorship, milestone tracking)
5. Demo/final assessment
6. Alumni follow-up and impact tracking

## Required Operating Artifacts
- Program charter and outcomes map
- Application rubric + panel score sheets
- Mentor assignment matrix
- Weekly operating report template
- Risk/issue log
- Milestone evidence repository
- Final cohort performance report

## Governance Structure
- **Program Director:** outcomes, stakeholder alignment
- **Program Operations Manager:** scheduling, workflow reliability
- **Founder Success Lead:** participant outcomes and interventions
- **Partnerships Lead:** mentor/corporate/investor network
- **Finance & Compliance:** budget, disbursement, reporting integrity

## SLAs / Service Standards (recommended)
- Application response within 7 business days
- Mentor matching completed within 14 days of cohort start
- Weekly founder check-ins minimum 1 touchpoint/startup
- Issue escalation response within 48 hours

## Risk Controls
- Attrition risk: early warning based on attendance + milestone slippage
- Budget risk: monthly variance threshold alerts (>10%)
- Delivery risk: session cancellation fallback pool
- Compliance risk: required-document checklist before disbursement

## Continuous Improvement Loop
- Cohort retrospective (founders + team + mentors)
- Compare planned vs actual milestones
- Update templates/rubrics before next cohort
- Maintain benchmark table versus peer programs
