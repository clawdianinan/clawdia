# Product Positioning

## Working Product Name
Innovation Program Manager (IPM)

## Positioning Statement
For innovation hubs, accelerators, public programs, and ecosystem builders, IPM is an execution OS that turns program design, cohort delivery, budgeting, and reporting into one integrated workflow.

## Problem
Most program teams run operations across fragmented tools (forms, sheets, chat, docs), causing:
- weak program visibility,
- inconsistent founder experience,
- poor budget/compliance tracking,
- slow reporting to funders/leadership.

## Core Value Proposition
- Configure program models fast (accelerator, grant, hybrid, rolling support)
- Run consistent selection and cohort workflows
- Track delivery and milestones in real time
- Manage budget and disbursements with evidence
- Export stakeholder-ready reports instantly

## Primary ICPs (Ideal Customer Profiles)
1. Innovation hubs and accelerators in Africa/emerging ecosystems
2. Government-backed entrepreneurship programs
3. University and corporate venture programs
4. Donor-funded startup support operators

## Differentiators
1. Multi-model templates (private + public + hybrid)
2. Built-in budget/compliance engine (not an afterthought)
3. Founder, mentor, and operator workflows in one system
4. Program-to-report pipeline with audit-friendly artifacts

## Success Narrative
IPM helps operators move from ad-hoc execution to repeatable program performance with measurable outcomes per cohort.
