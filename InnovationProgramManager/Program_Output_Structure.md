# Program Output Structure

## What the system should generate after questionnaire completion

## 1. Program Blueprint Pack
- Program one-pager
- Cohort calendar (week-by-week)
- Milestone map with owner and due dates
- Risk and governance plan

## 2. Selection Pack
- Application form schema
- Scoring rubric + panel template
- Interview guide
- Offer/waitlist/rejection templates

## 3. Delivery Pack
- Session schedule
- Mentor matching sheet
- Weekly founder check-in template
- Attendance and engagement trackers

## 4. Financial Pack
- Budget model (fixed + variable)
- Disbursement schedule
- Variance tracker
- Funding-source mapping

## 5. Reporting Pack
- Weekly operator dashboard
- Mid-program review report
- End-of-cohort performance report
- Funder/compliance evidence bundle

## 6. Alumni Pack
- 3/6/12-month follow-up schedule
- Outcome survey templates
- Referral/introduction tracker
