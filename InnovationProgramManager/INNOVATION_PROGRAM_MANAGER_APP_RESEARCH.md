## 3. What to Extract From Internet Research
For each program researched, create a structured markdown file including:

1. **Program Name & Organization**
2. **Geographic Focus & Reach**
3. **Program Structure:**
   - 3.1 Duration (weeks/months)
   - 3.2 Format (in-person, hybrid, virtual)
   - 3.3 Cohort size
4. **Curriculum Framework:**
   - 4.1 Learning tracks
   - 4.2 Core modules
   - 4.3 Mentorship structure
   - 4.4 Demo day/graduation requirements
5. **Financial Model:**
   - 5.1 Funding type (equity, grant, fee)
   - 5.2 Typical investment/grants
   - 5.3 Program costs (if disclosed)
6. **Selection Process:**
   - 6.1 Application criteria
   - 6.2 Selection timeline
   - 6.3 Success rates
7. **Success Metrics:**
   - 7.1 Funding raised by alumni
   - 7.2 Survival/growth rates
   - 7.3 Job creation metrics
8. **Operational Insights:**
   - 8.1 Team structure
   - 8.2 Partner networks
   - 8.3 Alumni support
9. **Publicly Available Templates:**
   - 9.1 Application forms
   - 9.2 Curriculum outlines
   - 9.3 Budget templates
   - 9.4 Reporting frameworks

**Data Source:** Only publicly available information from official websites, reports, and publications.
