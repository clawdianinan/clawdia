# PRDForge — Release Scope and Stabilization Checklist

## Release Objective
Ship a production-stable release candidate with onboarding, PRD generation loop, and monetization fully reliable.

## What Is In Scope (This Launch)
- Sign in and session reliability
- Project creation and workspace continuity
- PRD generation quality and response consistency
- Edit, export, and sharing stability
- Pricing/paywall and subscription lifecycle reliability
- Analytics instrumentation and dashboards

## What Is Out of Scope (Post-Launch)
- Large new feature modules
- Non-critical UI redesign
- Experimental integrations without QA coverage

## Must-Pass Stabilization Checks
- [ ] No open P0 defects
- [ ] P1 defects triaged with explicit owner and ETA
- [ ] Core flow smoke tests pass consecutively
- [ ] Error states are user-readable and recoverable
- [ ] Rate limits and usage limits enforced correctly
