## Automation Workflow

### FINANCIAL REPORTING WORKFLOW (NEW - Effective February 2026)

**Phase 1: Document Collection & Validation (Day 1-15)**
- Day 1-3: Initiate monthly financial checklist
- Day 4-10: Collect all financial source documents
- Day 11-15: Validate documents, resolve discrepancies
- **Gate Check:** Checklist must be 100% complete before proceeding

**Phase 2: Template Population & Analysis (Day 16-20)**
- Day 16-18: Populate IHS Financial Management Report Template
- Day 19-20: Validate template outputs, generate financial analysis
- **Prerequisite:** All source documents validated and approved

**Phase 3: Report Integration (Day 21-25)**
- Day 21-22: Extract financial data from template for monthly report
- Day 23-24: Draft financial section with analysis and commentary
- Day 25: Financial section review and approval

### DEPARTMENTAL REPORT WORKFLOW

**Day 1-3 (New Month)**
- Monitor for departmental report submissions
- Track submission status
- Initiate financial documents checklist

**Day 4 (Deadline Day)**
- Check all reports received
- Send acknowledgment to departments that submitted
- Financial: Begin document collection tracking

**Day 5 (First Reminder)**
- Send reminder to departments with missing reports
- Copy: Temi Kolawole (temi@iih.ng)
- Financial: Follow up on missing documents

**Day 7 (Second Reminder)**
- Send urgent reminder to departments still missing reports
- Copy: Temi Kolawole (temi@iih.ng)
- Financial: Escalate missing financial documents

**Day 10 (Financial Document Deadline)**
- All financial source documents must be received
- Begin document validation process
- Update checklist completion status

**Day 15 (Validation Complete Deadline)**
- All financial documents validated
- Checklist 100% complete
- Ready for template population

**Day 20 (Template Population Complete)**
- IHS template fully populated with monthly data
- Financial analysis generated
- Ready for report integration

**Day 25 (Compilation Day)**
- Compile all departmental reports
- Integrate financial section from template
- Draft Executive Summary and Conclusion
- Review and finalize complete report
- Submit to Temi for final review

## Mandatory Finalization Standard (Effective 2026-03-07)
1. Every monthly report must be finalized in Microsoft Word format (`.docx`) using the January report structure/format as the baseline.
2. Start from the latest approved previous-month report file by duplicating it, then edit content for the current month to preserve structure and formatting consistency.
3. The final Word report must include the official IIH letterhead/header (logo + institution identity) consistent with prior monthly report delivery format.
4. Markdown drafts are working files only; delivery file is always `.docx`.
5. Financial section must be embedded inside the main report as readable summary tables (not attachment-only/embedded references).
6. Consolidated narrative must include complete departmental submission content, rephrased into a unified professional report tone (not sparse bullet extracts).
7. Executive Summary and Conclusion must be expanded with strategic context, cross-department synthesis, and forward priorities.
8. File naming standard for final report:
   - `IIH_Monthly_Report_[Month]_[Year]_v[Version]_[YYYYMMDD].docx`
9. After finalization, send the report to the Managing Director’s IIH email (`temi@iih.ng`) with the `.docx` attached.
10. Copy of the sent email must be retained in Sent mailbox and report path logged in workspace notes.
